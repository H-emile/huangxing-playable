# 荒星筑巢

横屏 2D 生存建造小游戏（网页版可玩 Demo，微信小游戏版本同步开发中）。

## 玩法

在外星陨石带的废墟里采集材料，把材料装到庇护所的五个面（顶盖、左墙、右墙、基座、门）上，
撑过 12 波七种灾害。每波之间约 3 分钟准备期，出门、挖掘、建造、合成都要抢同一段时间。

- 操作：全部为点击/拖拽。点地面或废墟移动与挖掘，把背包材料拖到墙面格位安装，长按墙面修复。
- 单局 12 波，撑过第 12 波通关，之后可进无尽模式。
- 手机建议横屏持握；电脑浏览器直接打开即可。

## 技术

原生 JavaScript + Canvas 2D，不依赖游戏引擎。逻辑层与渲染层分离，逻辑层可被 Node.js 直接加载做无头数值模拟。
